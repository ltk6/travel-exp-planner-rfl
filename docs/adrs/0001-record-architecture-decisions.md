# 1. Record Architecture Decisions

Date: 2026-08-06

## Status

Accepted

## Context

The architectural decisions made on this project must be recorded to ensure a clear technical history, particularly as the system evolves from a monolithic baseline into a containerized, cloud-portable deployment.

## Decision

We will document significant architectural decisions using Architecture Decision Records (ADRs). The project adopts a simplified version of the Markdown Architecture Decision Record (MADR) format. All ADRs are stored in `docs/adrs/`.

## Consequences

See `docs/adrs/` for the ongoing record of major architectural decisions. All structural shifts in future phases will be documented here.
