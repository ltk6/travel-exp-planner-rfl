# 1. Record Architecture Decisions

**Date:** 2026-08-06  
**Status:** Accepted

## Context
A clear technical history is required as the system evolves from a monolithic baseline to a containerized, cloud-portable deployment.

## Decision
Document architectural decisions using simplified Markdown Architecture Decision Records (MADRs). Store all ADRs in `docs/adrs/`.

## Consequences
- `docs/adrs/` serves as the ongoing record of major architectural decisions.
- All structural shifts in future phases must be documented here before implementation.
